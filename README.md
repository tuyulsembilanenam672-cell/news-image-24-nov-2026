## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `/output/entry.png` (1024×1024, under 1 MiB). The image is a newspaper front page rendered from `index.html` with headless Chromium; `main.ts` needs only the Node standard library and no network.
